# Login & Registration Page

A modern and responsive **Login & Registration Page** built using **HTML, CSS, and JavaScript**.  
This project is beginner-friendly and demonstrates basic client-side authentication using **localStorage**.

# Features

- Toggle between **Login** and **Registration** forms
- Clean and responsive UI
- Basic form validation
- Stores registered user data using **localStorage**
- Login authentication using saved credentials
- Beginner-friendly and easy to understand code

# Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
